Security & architecture

  • ASP.NET Core, Entity Framework Core and Microsoft SQL Server
  • ASP.NET Core Identity with MFA, lockout and session management
  • Organisation-level data isolation, RBAC by module and record scope
  • CSRF/XSS/SQL-injection protection, rate limiting, secure cookies
  • Malware-scanned uploads stored outside the public web root
  • Immutable audit logs with before/after values
